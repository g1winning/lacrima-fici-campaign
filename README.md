# Lacrima Fici campaign proposal

Marketing campaign proposal for Lacrima Fici fig syrup (Romeo family, Shepparton, Victoria): retail buyers from 16 November 2026, shoppers from the February 2027 harvest. Prepared 24 October 2026. Working draft for the executive marketing team.

The site is static HTML built from the sections, copy and research in the campaign folder. The published page is `index.html`; the documents are under `docs/`.
